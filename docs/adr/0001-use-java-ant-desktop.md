# ADR 0001: Use Java + Ant for Desktop Application

## Status
Accepted

## Context
We need a cross-platform, maintainable desktop application for government services. The team is familiar with Java and Ant.

## Decision
Use Java 17+ and Apache Ant as the build tool.

## Consequences
- Pros: Strong tooling, widely supported, familiar language
- Cons: Some legacy dependencies, manual build configuration
